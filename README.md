# Anota Treino Home (Penpot)

Desenha 3 versões da Home do Anota Treino no estilo Escuro neutro, lado a lado na página "Home", usando cópias dos componentes da biblioteca "Anota Treino - Biblioteca". Não cria fluxos nem interações.

Como usar:
1. Abra o arquivo "HOME" no Penpot, com a biblioteca "Anota Treino - Biblioteca" conectada.
2. Aperte Ctrl+Alt+P e cole o endereço:
   https://estudio-orsi.github.io/anota-treino-home-plugin/manifest.json
3. Abra o plugin.
   - "Diagnóstico": só lê a biblioteca e o arquivo, não muda nada.
   - "Gerar homes": cria ou refaz a página Home.
   - "Baixar log": salva um arquivo .json com o diagnóstico e o log da última geração.

O plugin só roda no arquivo "HOME" e com a biblioteca conectada. Ao rodar de novo, apaga e refaz só a página que ele mesmo criou.
A permissão "allow:downloads" serve só para o botão "Baixar log".
